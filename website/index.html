What this is

CanIRunLLM answers one question: given the computer you already own, which AI models can it actually run well, and which one should you pick? It scans your real hardware, checks it against a registry of open-weight models, and tells you plainly what runs comfortably, what runs but slower, and what won't run at all — not after a long download and a crash, but before either happens.

That's the whole value: confidence instead of guesswork. No wasted downloads, no wondering if you need new hardware before you've even tried what you have, no vague "it depends." Just an answer, and a model recommendation to go with it.

Someone else's infrastructure, someone else's meter.

Why running it locally is worth it

Most software being built right now is agentic — a chain of LLM calls handling a task end to end, not one prompt and one answer. Look at what those calls are actually doing, though, and most of them aren't hard reasoning problems at all: routing a request, picking a tool, reformatting a result, deciding what to do next. Small, simple decisions, made over and over, dozens or hundreds of times to finish one task. Paying a cloud provider per call for that, at agent scale, adds up fast — for work a small model could handle just as well. That's the gap this fills: if your hardware can run that model, there's no reason to keep paying per call for it.

The same math holds outside of agents, too. A cloud AI service charges for every use, and it always will; a model on your own machine costs nothing once it's downloaded, whether you run it once or a thousand times a day. It can't be taken away the way a cloud tier can have its price raised or its access cut off overnight. And because nothing leaves your machine, there's no privacy policy standing between your data and the model — there's simply nothing sent anywhere to begin with, and no internet connection required either.

None of that means local wins everywhere. For the hardest problems, a frontier model in the cloud is still the better tool. But for the large share of work — agentic or not — that isn't a hard problem, local is good enough now, and that alone tips the balance.

What makes it different from a VRAM calculator

Every version judged on its own
A lighter build of a model isn't lumped in with the original — each one gets its own honest answer, because each genuinely needs a different amount of memory.
Multiple GPUs, done honestly
Two graphics cards doesn't automatically mean double the usable memory — you only get credit for that when it actually works that way on your setup.
Confidence, not false certainty
Every verdict comes with a confidence level, and estimated numbers are always labeled as estimates — never presented as measurements.
Local-first, always
No account, no cloud calls, no telemetry. Your hardware scan never leaves your machine.

Install

Download CanIRunLLM.exe and double-click it. A window opens showing your scan results, then opens the dashboard in your browser automatically.

Download CanIRunLLM.exe

Requires Python 3.10+.

pip install canirunllm
canirunllm scan

Windows with multiple Python versions installed? Your pip might point at an older one. Run py -0 to see what's installed, then target a specific version: py -3.11 -m pip install canirunllm. 

git clone https://github.com/jashwanthsai678/CaniRunLLM.git
cd CaniRunLLM
pip install -e .
canirunllm scan
🔒 CanIRunLLM does not upload your hardware information anywhere by default. The scan, the model evaluation, and the dashboard all run on your machine.
