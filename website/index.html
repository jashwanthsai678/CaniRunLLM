What this is

CanIRunLLM is a straight answer to one question: given the computer you already own, which AI models can it actually run well - and which one should you pick?

It scans your real hardware, checks it against a registry of real open-weight models, and tells you plainly what runs comfortably, what runs but slower, and what won't run at all - instead of you finding out the hard way, after a long download and a crash.

The value is simple: confidence instead of guesswork. No wasted downloads, no wondering whether you need new hardware before you've even tried what you have, and no vague "it depends" - just a clear answer, and a model recommendation to match it.

Why running it locally is worth it

It's free to use, every time. A cloud AI service charges per use, forever. A local model costs nothing once it's on your machine - run it once or a thousand times a day, the price doesn't change.

Nobody else can take it away. A cloud service can raise its price, change its limits, or shut down - on its own schedule. A model on your own disk keeps working regardless.

Your data never leaves your machine. Not a privacy policy to trust - simply nothing sent anywhere.

It works without the internet. No connection needed, no waiting on someone else's servers.

This isn't a claim that local always beats the cloud - for the hardest problems, it often doesn't. But for the everyday work most people actually use AI for, local is good enough today, and that makes it the better deal.

How it works

1
Scan your hardware
CPU, RAM, GPU, and VRAM — detected directly from your machine, nothing uploaded anywhere.
2
Evaluate real models
Every model + quantization pair is checked for weight memory, KV cache growth, runtime overhead, and safety margin — not just file size.
3
Get a plain-language verdict
"Runs comfortably," "Runs, but slower," or "Not enough resources" — each with the actual reasons, and an alternative model if one doesn't fit.
4
Drill down if you want
Every number — VRAM, RAM, KV cache, confidence — is one click away behind a "Technical details" toggle.

What makes it different from a VRAM calculator

Quantization-aware
Q4_K_M, Q8_0, and more — the same model at different quantizations is treated as a genuinely different artifact, because it is one.
Multi-GPU done honestly
2×8GB GPUs are never silently treated as one 16GB pool — only combined when the runtime actually supports splitting across them.
Confidence, not false certainty
Every verdict comes with a confidence level, and estimated numbers are always labeled as estimates — never presented as measurements.
Local-first, always
No account, no cloud calls, no telemetry. Your hardware scan never leaves your machine.

Install

Download CanIRunLLM.exe and double-click it. A window opens showing your scan results, then opens the dashboard in your browser automatically.

Download CanIRunLLM.exe

Requires Python 3.10+.

pip install canirunllm
canirunllm scan

Windows with multiple Python versions installed? Your pip might point at an older one. Run py -0 to see what's installed, then target a specific version: py -3.11 -m pip install canirunllm. 

git clone https://github.com/jashwanthsai678/CaniRunLLM.git
cd CaniRunLLM
pip install -e .
canirunllm scan
🔒 CanIRunLLM does not upload your hardware information anywhere by default. The scan, the model evaluation, and the dashboard all run on your machine.
